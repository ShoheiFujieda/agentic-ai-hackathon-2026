# 調査: 学生本人の大学の一覧をハブとして使う（筑波大学、2026-10-09）

デモの大学を筑波大学にした（ユーザーの希望）。学生は架空のまま（筑波大学 理工学群2年、埼玉県出身、つくば市在住、保護者は埼玉県在住）。

## 筑波大学の公開データ
- 民間奨学団体・地方公共団体の一覧ページ（https://www.tsukuba.ac.jp/campuslife/support-scholarship/scholarship-links/pg/ ）は、表の中身を `https://www.tsukuba.ac.jp/scholarship.json` から読み込んでいる
- JSON は1,550件（2018年度〜2028年度。2026年度は220件）。各件に 年度・対象（学群／大学院）・給与／貸与・団体名と掲載日・期限（limit）・詳細ページのリンク・区分（民間奨学団体／地方公共団体）がある。**AIで抜き出さなくても、コードで正確に読める**
- 詳細ページには「申請方法（大学申請／個人応募）」「申請期限」「提出書類」「詳細URL」が決まった項目で載る
- robots.txt: HTML と JSON は取得可。**PDF は原則取得禁止**（`Disallow: /*.pdf$`）
- 2026-10-09 時点で、学群生が応募できる募集は12件（例：吉川徹財団 10/18、岩佐教育文化財団 11/6、首藤奨学財団 11/13〔大学申請〕、TCS奨学会 11/27）

## 前回の照合結果との突き合わせ（`docs/experiments/2026-10-09_verify/`）
| 前回の応募経路の判定 | 筑波大学の一覧に載っていた数 |
|---|---|
| 大学経由 | **10/12**（ほとんどが2018年度から毎年掲載） |
| 直接応募 | 4/5 |
| 不明 | 7/10 |

- 締切の月が毎年そろっている（例：川村育英会 5〜6月、アイザワ記念育英財団・三菱UFJ信託奨学財団 4月、林レオロジー記念財団 9〜11月）。**8年分の履歴から「例年の募集時期」を出せる**
- 名前の照合は表記ゆれに弱い（例：「埼玉学生誘液会」は正しくは「埼玉学生誘掖会」で一致しなかった）

## 分かったこと
- 本人の大学の一覧は、大学経由の奨学金について「本人の大学に来ているか」「申請期限（学内）」「提出書類」をまとめて与えてくれる。設計当初「Webにないので解決できない」とした学内締切の問題も、公開している大学なら解決できる
- 筑波大学のような構造化データ（JSON）は大学ごとに形が違う。一般化するには、HTML／PDF の一覧を AI で読む方式（これまでの実験と同じ）も残す
- 取得の前に robots.txt を確かめる必要がある（これまでの実験では確かめていなかった）
