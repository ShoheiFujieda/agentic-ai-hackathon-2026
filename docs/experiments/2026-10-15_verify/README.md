# 実験: 絞り込み → 公式要項での照合 → コードでの判定（2026-10-15 の再実験）

`EXP_DATE=2026-10-15 uv run python scripts/exp_verify.py 30` を実行した（2026-10-09 の実験と同じ方法・同じ架空の学生。判定の基準日は 2026-10-15）。判定は `hackathon_agent/scholarship/judge.py`（AIは判定しない）。生データは `result.json`。この実験は検索つきの結果に依存するため、候補の顔ぶれは日々変わる。

## 分かったこと
- **「10月の時点で、約半数がすでに募集終了」は再現した。** 照合できた件数のうち、10/9 は28件中12件（43%）、10/15 は29件中14件（48%）。民間奨学金の締切は4〜6月に集中する。「締切後に気づく」問題の裏付けになる
- **引用の照合は、今回も全件一致（81／81）。** 作り話の引用は判定に使われていない
- **応募できる（確認済み）が出た。** 今回は1件（TCS 奨学会。締切 2026-11-27）。間に合うものとして、林レオロジー記念財団（締切 2026-10-23）も見つかった（10/9 と同じ）
- **「要確認」が多いのは、見落とし防止のため。** 確認できない条件を「合っている」とは判定しない設計
- **大学経由の割合は日によって大きく変わる**（44% → 28%）。候補の顔ぶれが違うため。指定校かどうかは Web だけでは分からないことが多い、という結論は変わらない
- 所要時間は6.6分 → 4.0分。Gemini の応答速度によって変わる（本番のツールとは別の、実験用のスクリプトでの時間）

## 注意
- 比較は、同じ方法・同じ架空の学生での再実験であり、正解データ（網羅した奨学金の全体）との再現率を測ったものではない。比較実験（方式A〜C 対 本方式）の数値化は「拡張予定」のまま
