## 分かったこと
- 集合拡張（SEAL）は奨学金でも機能する。候補は1回の検索の約10件から約680件に増えた
- 最良のハブは、大学が公開している民間奨学金の一覧
- 候補には、留学生向け・他県の自治体・他大学の学内基金が混ざる。全件の公式ページを読むと高くつくので、照合（⑥）の前に安い絞り込みが必要
- 他大学の一覧に載る奨学金の多くは「指定大学を通してのみ応募できる」タイプ。本人の大学が指定されているかは Web だけでは分からないことが多く、「要確認」として出す必要がある
- Chao 推定量（f1=379, f2=107）で、一覧ページに載る団体の総数は約1,350件、カバー率は約50%と推定。ただし一覧ページどうしは独立した標本ではないため目安
- 呼び出しが続くと 429（呼び出し回数の制限）が出る。待って再試行する処理が必要

## 次に確かめること
1. PDF の一覧ページも読む
2. 安い絞り込み（留学生向け・他県限定などを除く）→ 候補ごとの照合（⑥）で、この学生が実際に応募できる件数を出す
3. 1回だけの検索（方式A）と、同じ検索回数で比べる
