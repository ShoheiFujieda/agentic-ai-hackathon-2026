# 実験: 種集め → 一覧ページの発見（2026-10-15 の再実験）

`EXP_DATE=2026-10-15 uv run python scripts/exp_seed_hub.py` を実行した（2026-10-09 の実験と同じ方法・同じ架空の学生：東京都内の私立大学・理工学部機械系2年、埼玉県出身、保護者は埼玉県在住、JASSO 第一種貸与を受給中）。生データは `result.json`。

## 結果（10/9 との比較）
| 項目 | 10/9 | 10/15 |
|---|---|---|
| ① 種（最初の検索で見つかった奨学金） | 4件 | 5件 |
| ② 一覧ページ（種が2つ以上載っているページ） | 11件 | 14件 |
| ③ 一覧ページから新たに見つかった候補 | 676件 | 572件 |
| 検索つき呼び出し／ページ取得 | 6回／20回 | 6回／20回 |

## 分かったこと
- **集合拡張は再現した。** 種の4〜5件から、一覧ページ経由で新たに約570〜680件の候補が見つかった。日によって検索結果が変わるため、件数は同じにならない（検索つきの結果は日々変わる）
- 検索回数・取得回数の上限（6回・20回）の中で、同じ規模の拡張ができた
- コンソールの出力は日本語が文字化けすることがあるが、`result.json` は UTF-8 で正しく保存されている
