# 実験: 絞り込み → 公式要項での照合 → コードでの判定（2026-10-09）

`scripts/exp_verify.py 30` を実行した。学生は前回と同じ架空の人物（東京都内の私立大学・理工学部機械系2年、埼玉県出身、保護者は埼玉県在住、JASSO 第一種貸与を受給中）。判定は `hackathon_agent/scholarship/judge.py`（AIは判定しない）。生データは `result.json`。

## 結果
| 項目 | 値 |
|---|---|
| PDF の一覧ページを追加 | 7件（項目872） |
| 候補 → 安い絞り込み後 | 906件 → 835件（除外：他大学の学内制度25、他の地域36、留学生向け10） |
| 照合した候補 | 30件（多くの一覧に載る20件＋無作為10件）。6.6分、検索つき呼び出し30回（裏の検索176回）、抜き出し42回、ページ取得50回 |
| 判定 | 要確認14、**募集終了12**、対象外1、公式情報なし1、エラー2（AIの出力に余計な文字。修正済み）、応募できる0 |
| 引用の照合 | 照合した60件の引用は、すべて原文と一致 |
| 応募の経路 | 大学経由12、直接応募5、不明10 |
| 締切の月 | 2026年4月4件、5月4件、6月1件、**10月2件**、ほか |

## 分かったこと
- **10月の時点では、照合できた28件のうち12件がすでに募集終了。** 民間奨学金の締切は4〜5月に集中する。「締切後に気づく」問題を数字で裏付けた
- **今まさに間に合うものも見つかった。** 林レオロジー記念財団は、2027年度の奨学生を 2026-09-01〜10-23 に募集中
- **大学経由が44%（12/27）。** 指定校かどうかは Web だけでは分からないことが多い
- **AIの作り話を引用の照合で捕まえられる。** 試運転では、文字化けしたページから、AIが存在しない文（「本年2年次在学以上の者」）を引用として返した。コードの照合がこれを不一致とし、判定に使わなかった。文字コードの判定（meta charset）と、波線・記号の違いを同一とみなす処理を加えた後は、本物の引用はすべて一致した
- **「要確認」が多い。** 見落とし防止のため、分野が合わないときや地域名が「都内」のような表現のときも対象外にしていない（例：医学部生向けの論文賞が要確認に残った）

## 設計への反映（案）
1. 募集終了のものは捨てずに、「例年の募集時期」として来年の準備カレンダーに出す（締切後に気づく問題への直接の対策）
2. 学生本人の大学が公開している民間奨学金一覧をハブとして使い、大学経由の奨学金が本人の大学に来ているかを確認する
3. 分野の判定に「明らかに別の分野」（医学、歯学、薬学、看護など）の一覧を加え、要確認を減らす
4. 奨学金データは学生をまたいで共有する（1件あたり約13秒・検索約6回。835件を毎回調べると約3時間かかるため、一度調べた結果を全員で使い、学生ごとには判定だけを行う）
