## 事前に撮るデモ動画（2本）
撮影前に、同じ条件で1回検索して、キャッシュを温めておく（`powershell -File scripts/warm_prod.ps1`。約30秒で結果が出る）。
- **デモ①（約50秒、スライド4）**: 公開URLにログイン → 「入力例を入れてみる」→「奨学金を探す」→ 結果の表（応募できる／要確認／未確認／募集終了）→「確認すること」→ 立場を「卒業後（社会人）」・目的を「研究」に替えて再検索 → 結果を保存 → CSV
- **デモ②（約35秒、スライド5）**: チャットで「『（奨学金の名前）』を共有リストに追加したい。公式ページは https://… 」と入力 → 承認待ち → 確認ダイアログで許可 → 完了 → 右の「操作の記録」
- 画面は1920×1080、ブラウザの拡大は100〜125%。個人情報や、パスワードが映らないようにする（ログイン後の画面から撮る）。

## スライドへの動画の入れ方
1. スライド4（デモ①）、スライド5（デモ②）を開く
2. ［挿入］→［ビデオ］→［このコンピューター上のビデオ］で動画を選ぶ
3. 点線の枠に重ねて、サイズを合わせる。枠（点線の四角）は削除してよい
4. ［再生］タブ →［開始］を「自動」にすると、スライドが出たら再生される（ナレーションを重ねるなら、動画の音量をミュート）
5. 全体を、画面録画（PowerPoint の［スライド ショー］→［記録］、または OBS）で撮り、約3分に収める
6. YouTube に「限定公開」でなく「公開」でアップロードする（提出の条件）

## 電子音声のナレーション（声を出さずに撮る場合）
`powershell -File scripts/make_narration.ps1`（既定は Windows の日本語の音声「Microsoft Haruka」、話す速さ 1.2）で、スライドごとの音声ファイル `docs/submission/narration/slide01.wav`〜`slide08.wav` ができる（Git には入れない）。`-Voice "Microsoft Ichiro"`（男性）、`-Rate 1.0`（標準の速さ）で変えられる。
- スライドごとに、［挿入］→［オーディオ］→［このコンピューター上のオーディオ］で入れ、［再生］タブの［開始］を「自動」にする
- デモ動画のスライド（4・5）は、動画の音量をミュートにして、音声を重ねる（動画のほうが長いので、音声は動画の途中で終わる。気になる場合は、動画の頭を少し切る）
- 英字の略語（ADK、CSV、AI など）は、読み間違えないよう、スクリプトの中でカナに直している。**必ず一度、全部を聞いて、読み間違いや不自然な間がないか確認する**（直す場合は `narration/script.json` の文面、または `make_narration.ps1` の置き換え表）
