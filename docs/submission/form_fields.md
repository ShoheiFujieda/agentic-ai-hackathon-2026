## タブ「プロジェクト紹介」
**課題と解決**（800字まで・一部の Markdown のみ／400字）
```
**課題**
奨学金は、大学・財団・自治体のサイトに散らばっています。生成AIに「全部教えて」と聞くと、上位数件しか読まない、古い年度や募集終了を混ぜる、自分が対象外の条件を見落とす、という穴があります。実測では、素のAIが挙げた34件のうち12件（約3分の1）が、公式ページで見ると募集終了でした。

**解決**
- 探すのはAI（Gemini＋Google検索）、**応募できるかの判定は、公式ページを読んだうえでコード**が行います
- 条件は原文の引用つきで抜き出し、引用が原文にあるかをコードで照合。作り話は判定に使いません
- 「応募できる／要確認／目的が違う／未確認／募集終了」に分け、確認できないものを隠しません
- 高校生〜社会人、学業・留学・研究・活動の目的に対応

**正直な限界**
素のAIとの比較（4つの立場・各1回）で、見つかる件数は同程度でした。差は「確かさ」です。
```
